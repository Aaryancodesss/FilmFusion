# 🎬 FilmFusion — Modern Movie Search App

A sleek and immersive movie search web application built using **HTML, CSS, and JavaScript**.
Designed with a cinematic dark theme, smooth animations, and interactive UI elements, this project showcases both **modern frontend design** and **JavaScript higher-order functions (HOFs)**.

---

## 🚀 Features

✨ **Modern UI/UX**

* Dark, cinematic theme with animated gradient backgrounds
* Glassmorphism-based movie cards
* Smooth transitions and micro-interactions

🔍 **Search Functionality**

* Real-time movie search using `.filter()`
* Instant results based on user input

🎥 **Dynamic Rendering**

* Movies displayed using `.map()`
* Clean and responsive grid layout

📊 **Sorting Capability**

* Sort movies by rating, year, or title using `.sort()`

🖱️ **Interactive Effects**

* Cursor glow effect with smooth tracking
* 3D tilt effect on movie cards
* Hover animations and spotlight effects

📱 **Fully Responsive**

* Optimized for mobile, tablet, and desktop

---

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling, animations, glassmorphism
* **JavaScript (Vanilla)** — Logic and interactivity
* **TMDB API** — Movie data (optional integration)

---

## 🧠 Concepts Used

* Higher-Order Functions:

  * `.filter()` → Search functionality
  * `.map()` → Rendering UI components
  * `.sort()` → Sorting data

* DOM Manipulation

* Event Handling

* Responsive Design

* CSS Animations & Transitions
